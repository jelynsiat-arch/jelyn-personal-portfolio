JELYN SIAT - PERSONAL PORTFOLIO

HOW TO RUN
1. Extract the ZIP file.
2. Open the jelyn_portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension in VS Code.

BEFORE PUBLISHING
1. Replace images/profile-placeholder.svg with your own photo (update the image path in index.html if you use a different filename).
2. In index.html, replace the sample GitHub, LinkedIn, and email links with your real links.
3. In script.js, replace your.email@example.com with your real email address.
4. Update project details and skills to reflect your actual experience.
5. Only list certificates and achievements you have earned.

NOTE
The contact form opens the visitor's default email app. It does not send messages to a server or store submissions.
